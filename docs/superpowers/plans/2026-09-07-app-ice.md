# ccs-app (Ice) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Swift menu bar app with `ccs-app`, an Ice (ducktape-ui) daemon that links ccs as a library, runs the gateway and the watcher in-process, and works on macOS and Linux.

**Architecture:** `ccs` becomes lib + bin with an owned `Env`; the app's Rust side exposes typed externs over `cmd::readings`, `cmd::switch`, `cmd::poll`, `serve::listen`/`cmd::desk`; the UI is Ice: one window on every platform, a tray on macOS with fixed account slots.

**Tech Stack:** Rust 2024, iced =0.14.0 (smol executor), ui-lang / ui-lang-runtime / ui-lang-build by git rev, notify-rust.

**Spec:** `docs/superpowers/specs/2026-09-07-app-ice-design.md`

## Global Constraints

- The app never polls the API itself; the in-process watcher does, and the UI reads the cache.
- Credential store trait objects are `Send + Sync`; `Env` is shared as `Arc<Env>`.
- Tray slots: 8 Claude, 4 Codex, guarded by `when`.
- Bundle id `dev.orthory.ccs`, `LSUIElement` on macOS; the binary is `ccs-app`.
- No new dependency in the `ccs` root crate; the app crate may add `notify-rust`.

### Task 1: ccs as a library with an owned `Env`

**Files:** Create `src/lib.rs`, `src/env.rs`; Modify `src/main.rs`, `src/creds.rs` (`+ Send + Sync`), `src/codex.rs` (same), `src/cmd.rs` (`pub fn readings`, `pub fn switch`, `pub fn poll`, `pub fn desk`, `pub struct Poll`), `src/serve.rs` (`pub use` what the desk loop needs).

**Interfaces produced:** `ccs::env::Env { pub fn open() -> Result<Env>; pub fn ctx(&self) -> cmd::Ctx<'_> }`; `ccs::cmd::{readings, switch, poll, desk, Poll, Cached}`; `ccs::watch::Snapshot`.

- [ ] Tests: `Env::open` against a temp `HOME`/`CLAUDE_CONFIG_DIR` builds and `ctx()` lists an empty stash; `poll` over a fixture returns one entry per account with probe errors and no events; `switch` installs the account (reuse the Fixture).
- [ ] Run: fails (no `env` module). Implement. `make check` green. Commit `refactor: ccs as a library with an owned Env`.
